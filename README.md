# wald-agent-
Wald is a decision-oriented AI engine designed to turn unstructured context into fast, structured, and confidence-aware decisions. Instead of generating free-form text, Wald evaluates predefined choices, scores, and conditions, returning typed outputs and probability distributions that software can use directly.

Wald is built for intent classification, request routing, risk assessment, tool selection, automated review, and agent workflows where speed, predictability, and control matter.

Evidence in. Decisions out.
